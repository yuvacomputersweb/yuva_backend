⬆ Import Products from Excel

How it works:
  • Download the template first using the Export Excel button on the Products list page — it has the correct sheet names and column order.
  • Fill in your data starting from Row 3 (Row 1 = help text, Row 2 = column headers).
  • Sheets are processed in order: Categories → Brands → UsageTags → Products → Variants → Reviews → Coupons → SiteConfig.
  • If a row has an id, it will be updated. If id is blank, it will be created (matched by SKU / slug / code).
  • Invalid rows are skipped with a warning — the rest still import.
  • For images, paste a public URL (direct image link or Google Drive share link).
  • For usage_tag_slugs use comma-separated slugs, e.g. gaming,coding.
